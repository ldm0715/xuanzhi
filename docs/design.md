# 设计理念：为什么长这样

宣纸不是"套了一层古风皮的博客"，而是把整套界面当作**一件纸上的器物**来做：每个页面都借一个真实物件（诗笺、信封、函套、印谱、书卷）来组织信息，版式里只出现"纸、墨、朱砂"三种材料。这一篇讲这套语言是怎么落地的。

## 一张纸，两种光

- **亮色 = 宣纸**：`#F7F3EB` 纸底 + 24px 稿纸格纹 + 墨阶四档文字
- **暗色 = 夜墨**：`#282219` 底 + 纸色文字，跟随系统或手动切换，带防闪白恢复

明暗切换是**圆形揭示动画**（View Transitions）：切暗色时画面以按钮为圆心收拢、切亮色时放出；不支持的浏览器或系统减弱动画时瞬时切换，不阻塞阅读。

材料分三层，各司其职：

- **纸系**——底、格纹、折痕浅线，刻意不随点缀色变化，保持"纸就是纸"
- **墨阶**——正文的浓淡（`strong` 浓墨、`del` 褪色、引导线），语义信息留在墨里
- **朱饰系**——印章、邮戳、着重号、外链标记等"点缀性"标记，随点缀色在朱砂 / 黛青间切换

正文 `<em>` 用中文**着重号**而不是斜体：霞鹜文楷没有真正的斜体字面，浏览器合成假斜体在汉字上很脏——这是"文楷正文"这个前提带来的必然选择。

## 点缀色：陶土橘 / 黛青

`hugo.toml` 里一行选默认点缀色：

- `terracotta` 陶土橘 `#DA7756`（默认，朱砂装饰）
- `indigo` 黛青 `#425066`（青印装饰）

**外观面板**（导航栏调色板按钮）把选择权交给访客：5 种纸面（稿纸格 / 素纸 / 微噪点 / 噪点+暗角 / 稀疏信笺纹）× 2 种点缀色 × 4 种分隔线（一笔 / 断栏 / 墨点 / 飞白），每个选项附一张按真实尺度铺开的大样张。选择存在 localStorage，无记录时回落 `params.accent` 与默认格纹。

## 页面叙事：每页一件器物

**首页 = 诗笺 + 红框封。** 上半是欢迎区：一张竖排繁体诗笺，诗由构建期预取、访客每次到访随机换一首，取不到或不合格就静默保留兜底的一首。下半是文章卡片：素纸底 + 一道朱丝框，右上朱砂日期邮戳（悬停像盖一次章），右下角一枚极淡的**印记**——八式水墨小品（远山晓日 / 竹影 / 空亭听雨 / 汀洲孤雁 / 孤舟远影 / 红杏出墙 / 云岫 / 杨柳岸）按标题哈希生成，同一篇永远同一幅；想换成自己的图就在 front matter 给 `cover`（见 [writing.md](writing.md)）。

**归档页 = 毛笔纪年 · 朱印领月。** 细宋年份压淡朱小印，左侧一枚按年份推算的**干支闲章**（哪一年都对得上）；月份缩成行内小朱印 + 汉字篇数，月份之间全靠留白。文章行是传统目录式：日期居左、点线引导、题名贴右——刻意**不带摘要**，这是目录的语言。

**分类与标签各有形制。** 分类索引是**通栏书柜**：函套站在搁板上（搁板按行高重复画出来，函套折到哪层都有一整条长板）；标签索引是**印谱**：每个标签一方朱印，朱文 / 白文按奇偶相间、逐枚微倾，篇数作汉字边款缀于印下。词页同样成物——分类词页像**打开函套**（顶边露出一排册脊、函面签条写类名与篇数），标签词页像**钤在纸上**（96px 大印直接盖在纸面）。

**文章页 = 书卷。** 题跋折痕双线分隔，元数据是"落款式"的：「撰于」引首章、分类的毛笔记号（一撇，取评点的"抹"）、印章式标签；文末一枚**落款章**（站名四字，逐字入格自动成阵，印泥飞白）；上下篇是**线装翻页**，悬停轻移 + 淡朱暖洇。

右下角一枚朱印（站名首字）是**文章工具栏**，也是一枚**阅读进度印**——可拖动。收起时，印面外一圈**方框**随阅读进度描边填充；**用方不用圆**，因为印本来就是方的（方印），圆环跟形制不对路。点开展开四格：「回到顶部 / 分享 / 目录 / 进度」，此时方框隐去、印面回到纯朱印，末位那格**直接显示**已读百分比——它是指示不是控件，所以没有可点的动作。分享把「站名 - 标题 - 地址」写进剪贴板并弹一张牛皮纸卡片。

**关于页 = 一件例外：它刻意不做成器物。** 不套框、不设站语，就是普通 markdown 排下来，只在三处收了一收——分节标题沿用文章页那套（毛笔记号 + 字号层级）；自述块是左像右文的双栏（左栏 132px 一张方形人像，没图时才是朱印）；版权页压到注脚体量、里面的链接只让下划线着色。

试过把版权页做成一枚**藏书票**（双线朱框 + 白文站名印 + 站语），撤了。理由值得记下来：那套形制要成立，就得替使用者决定印面取哪个字、站语用哪一句、框用几道线——可"关于本站"这一节本来就是顺手交代几句出处，**不值得为它规定这么多**。器物化的前提是那件东西本身有分量；分量不够时硬套，套出来的只是装饰。

**不是每页都非得是件器物。**

## 阅读的取舍

- **单栏 800px**，文章页放宽到 1150px（头栏与页脚同步变档），入场淡入
- **目录（TOC）** 带 scrollspy 高亮；条目多于 10 条自动折叠成长目录，阅读到哪层哪层展开
- **代码块**双明暗高亮（变量驱动），带复制按钮
- **图片**：page bundle 里与文章同目录，构建时自动压成 WebP + 三档响应式 srcset；点图进入**图窗**——照片在"同一张纸"上放大（同纸色遮罩虚化、裱边画框），支持 ←→ 翻页、滚轮 / 双击缩放、拖动、双指捏合。**无 JS 时退化成"点开看原图"的普通链接**
- **公式在构建期渲染**（KaTeX 输出静态 HTML）：禁 JS、爬虫、RSS 阅读器都能读到排好的公式，客户端不加载脚本
- **外链**在服务端标记（新标签打开 + ↗ 记号），`mailto:` 之类的链接不会误伤
- **媒体**：站内自托管的视频 / 音频走 `video` / `audio` / `playlist` 三个短代码，分别由 **Plyr**（视频）与 **APlayer**（音频，支持播放列表与 `.lrc` 歌词）渲染，皮肤已覆写成宣纸风（牛皮纸签条那套）。这两个库**只在嵌了媒体的页面加载**。分工是「外部平台用裸 iframe，自托管媒体用短代码」——bilibili / YouTube 没有可直链的媒体文件，短代码不去假装能包住它们
- **打印**走专门的打印样式：黑白还原、隐藏头栏 / 目录 / 工具栏 / 播放器，外链把地址印出来
- **站内搜索（Pagefind）**：中文分词原生支持；索引由构建后的一步 `npx pagefind --site public` 生成，运行时按需加载的是**自托管的索引文件**，这一块不发外部请求。使用与构建要求见 [configuration.md「站内搜索：能力与边界」](configuration.md#站内搜索能力与边界)

## 内容即资产

- 霞鹜文楷、思源宋体、JetBrains Mono、KaTeX、Plyr、APlayer、Pagefind 索引一律**自托管**（Pagefind 只在你的构建期跑一次，运行期加载的都是本地文件）；字体按 `unicode-range` 切片按需加载。Plyr 的图标 sprite 默认指向它的 CDN，主题已改指自托管的 `static/vendor/plyr.svg`
- **对外请求只有一处：首页诗笺。** 它向「诗泉」（`poetry.palemoky.com`）取七言 / 五言绝句——构建期用 `resources.GetRemote` 烘一首进 HTML，浏览器端 `site.js` 每次到访再 `fetch` 一次随机换新。取不到、超时、CORS 失败或校验不合格时**静默保留已烘入的那首**，页面不受影响。端点写在 `layouts/home.html` 的 `data-poem-api` 上，**想彻底不联网就改掉或删掉这个属性**（删掉后 `site.js` 会回落到同一个默认地址，所以两处一起改，或直接改掉 `site.js` 里的默认值）
- **图片和文章在同一个 Git 仓库**是本主题的根基约定：不要用外部图床——本地所见即所得，构建产物可整站镜像（见 [writing.md](writing.md)）
- 所有图标取自 `@material-design-icons/svg` 官方包，不靠记忆手写
