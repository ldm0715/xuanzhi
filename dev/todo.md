## 备查（考虑中，未定做不做）

| 条目 | 一句话说明 |
|---|---|
| 相关文章 `.Related` | Hugo 内置按关键词/日期算相关度；文末加「延伸阅读」能提升停留时长，不做则每篇都是"死胡同" |
| `lastmod` / `enableGitInfo` | 现在只显示发布日期，改过的文章看不出来。注意：**它会让每次 commit 都改变页面**，对缓存不友好 |
| 面包屑 `BreadcrumbList` | 文章页没有"首页 › 分类 › 文章"的路径，可与 JSON-LD 一并做 |
| series 分类法 | 连载型内容比 tags 更合适，Hugo 加一行 `[taxonomies]` 即可，但需配套模板 |
| 作者页 | 单作者站用不上，将来多人写才需要 |

后四条同时有一句**倾向不做**的结论：单作者、缓存不友好的代价 > 收益。
